# 🔧 4-Cylinder Engine – SOLIDWORKS 3D Model

A detailed **4-cylinder internal combustion engine** modeled and assembled using **SOLIDWORKS**.

This project focuses on mechanical design, 3D CAD modeling, assembly, and motion visualization of the major components of a conventional four-cylinder engine.

## 📌 Project Overview

This project involves the complete 3D modeling and assembly of a **4-cylinder engine** using SOLIDWORKS.

The model includes major engine components such as the:

- Engine block
- Cylinder head
- Pistons
- Connecting rods
- Crankshaft
- Camshaft
- Valves
- Timing components
- Flywheel
- Oil pan
- Intake and exhaust components
- Fasteners and supporting components


## 🎯 Objectives

The main objectives of this project are:

- To develop practical skills in **SOLIDWORKS 3D modeling**
- To understand the mechanical structure of a 4-cylinder engine
- To model individual engine components using appropriate CAD features
- To create a complete mechanical assembly using mates
- To understand the relationship between the crankshaft, pistons, connecting rods, and camshaft
- To visualize the mechanical motion of the engine
- To improve skills in mechanical design and CAD-based product development

## ⚙️ Engine Configuration

The modeled engine follows a conventional **inline 4-cylinder configuration**.

### Basic Configuration

- **Engine type:** 4-cylinder internal combustion engine
- **Cylinder arrangement:** Inline-4
- **Piston arrangement:** 4 pistons
- **Crankshaft:** Multi-throw crankshaft
- **Connecting rods:** 4
- **Camshaft:** Single camshaft configuration
- **Valve system:** Intake and exhaust valves
- **CAD platform:** SOLIDWORKS


## 🧩 Major Components

### 1. Engine Block
The engine block forms the main structural body of the engine and contains the four cylinder bores.

### 2. Pistons
Four pistons are modeled to reciprocate inside the cylinder bores.

### 3. Connecting Rods
Each connecting rod connects a piston to the crankshaft and transfers the reciprocating motion of the piston to the crankshaft.

### 4. Crankshaft
The crankshaft converts the reciprocating motion of the pistons into rotational motion.

### 5. Cylinder Head
The cylinder head contains the combustion chambers and supports the valve mechanism.

### 6. Valves
The intake and exhaust valves control the flow of gases into and out of each cylinder.

### 7. Camshaft
The camshaft controls the opening and closing of the valves according to the engine cycle.

### 8. Flywheel
The flywheel stores rotational energy and helps maintain smoother crankshaft rotation.

## 🔄 Engine Motion

The engine assembly is designed to demonstrate the relationship between:

**Crankshaft → Connecting Rod → Piston**

and

**Crankshaft → Timing Mechanism → Camshaft → Valves**

The crankshaft rotation produces reciprocating piston motion, while the camshaft operates the intake and exhaust valves at the required timing.

### Four-Stroke Cycle

The model represents the basic operation of a four-stroke engine:

1. **Intake**
   - Intake valve opens
   - Piston moves downward
   - Air/fuel mixture enters the cylinder

2. **Compression**
   - Both valves remain closed
   - Piston moves upward
   - Mixture is compressed

3. **Power**
   - Combustion produces expanding gases
   - Piston is forced downward
   - Crankshaft receives rotational energy

4. **Exhaust**
   - Exhaust valve opens
   - Piston moves upward
   - Exhaust gases leave the cylinder
